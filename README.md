# Ganesh Chandan — Portfolio

A complete, gallery-free rebuild of [kganeshchandan.github.io](https://kganeshchandan.github.io/).

## Design direction

Editorial engineering: strong typography, visible structure, restrained motion, and one warm signal color. The site prioritizes current work, professional experience, and research rather than personal photography or generic template sections.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

The site is plain HTML, CSS, and JavaScript and can be published directly from the repository root with GitHub Pages.
