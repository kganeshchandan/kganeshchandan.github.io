# Portfolio evidence archive

This directory preserves the factual corpus used to build and audit the portfolio. It is intentionally more detailed than the public-facing website.

## Contents

- [`portfolio-factual-dossier.md`](portfolio-factual-dossier.md) — reconciled résumé, professional experience, education, awards, publications, project evidence, chronology, and publication cautions.
- [`account-owned-github-inventory.md`](account-owned-github-inventory.md) — human-readable evidence for all 28 public repositories owned by `kganeshchandan` at the snapshot date.
- [`account-owned-github-inventory.json`](account-owned-github-inventory.json) — machine-readable metadata and repository evidence for those 28 repositories.
- [`associated-github-projects.md`](associated-github-projects.md) — commit-attributed evidence for nine public projects hosted by DevaLab, D4-course, Virtual Labs, and collaborators.
- [`../resume.pdf`](../resume.pdf) — résumé used as the primary supplied source.

## Scope

The audited GitHub corpus contains 37 public repository URLs:

- 28 account-owned repositories;
- nine externally hosted organization or collaboration repositories.

Some URLs are mirrors, organization copies, or aggregate versions of the same underlying work and must not be presented as independent projects.

## Evidence policy

- Résumé claims are preserved as supplied rather than silently strengthened.
- Publication metadata uses DOI/Crossref records where résumé wording differs.
- Repository creation, update, and push timestamps have different meanings.
- Commit attribution supports contribution claims but does not imply sole intellectual ownership.
- Forks, coursework, public implementations, private implementations, peer-reviewed papers, under-review work, patents, and professional systems are classified separately.
- Proprietary Samsung details remain limited to résumé-approved wording.
